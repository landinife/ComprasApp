# ComprasApp

Control y seguimiento de órdenes de compra (OC) de la metalúrgica. App web de un solo archivo, pensada para el teléfono y la PC.

- App publicada: https://landinife.github.io/ComprasApp/
- Código: `docs/index.html` (GitHub Pages publica la carpeta `/docs`).
- Datos: Firebase (proyecto `tpfapps-5f226`), compartido con StockApp. Usa los mismos usuarios que StockApp con el permiso "Compras".
- Las reglas de Firebase son compartidas y están en el repositorio StockApp (`firestore.rules`).

El código está a la vista; los datos (CUIT incluidos) quedan protegidos por el inicio de sesión y las reglas de Firebase.
